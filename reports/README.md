# Generated and historical reports

Files below this directory are point-in-time audit, test-inventory, and tool
receipts. They are not current implementation guidance and are intentionally
not rewritten when the code they describe is retired.

In particular, references to the former Groth16, Poseidon, VKDB, `zk-test`, or
`bls12_381_pka` clear-signing implementation describe historical snapshots.
That implementation is absent from the current workspace. Current contributor
guidance lives in the root README and `docs/`; the retirement record is
`docs/archive/zk-clear-sign-retirement.md`.
