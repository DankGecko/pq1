# Historical external review outputs

These files are immutable outputs returned by earlier external research runs.
They are retained as audit evidence and may describe repository state that no
longer exists. They are not regenerated, normative, or current contributor
guidance. In particular, any Groth16, Poseidon, or VKDB description predates
the clear-signing retirement recorded in
`docs/archive/zk-clear-sign-retirement.md`.
